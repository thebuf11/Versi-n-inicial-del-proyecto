# Awesome DESIGN.md

Reference library from https://github.com/VoltAgent/awesome-design-md.

1. List `design-md/` to see available sites; each has a `DESIGN.md` (and README).
2. Read the DESIGN.md that best fits the user's wanted style.
3. Extract tokens (colors, typography, spacing, radii, shadows) into CSS custom properties and apply them to the project; do not copy brand logos or trademarks.
